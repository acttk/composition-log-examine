# 日志夜巡（Nightwatch）前端设计规范

> 版本 1.0 · 2026-09-03 · 适用于 web/index.html 单页应用

## 1. 设计立场

这是给一个人用的夜间巡检台。用户在一天结束时把项目日志投放进来，
工具先压缩去噪、再分轨读取。界面只做一件事：**让「投放 → 压缩 → 读取」这条管线一目了然**。

三个不可妥协的原则：

1. **结构即信息**：双轨制（轨道 A 代码统计 / 轨道 B 模型分析）是产品的核心二元性，
   它体现为贯穿全站的双色语义，而不是装饰。
2. **签名元素只有一个**：压缩塌缩可视化（8 MB 噪声 → 75 K tokens 信号）。
   它是工具的灵魂魔法，占据预估区视觉中心；其余一切保持安静。
3. **数据穿工装**：所有计量（行数、tokens、耗时、金额）用等宽字体右对齐，
   这是日志终端的本体语汇；叙述文字用正文字体，两者永不相混。

## 2. 色彩

墨绿黑值班室底 + 双语义强调色。全部色值如下：

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0C1210` | 页面底色（墨绿黑，非纯黑） |
| `--bg-raised` | `#131B17` | 卡片面 |
| `--bg-inset` | `#0A100D` | 内嵌区、表头、代码块 |
| `--line` | `#243129` | 边框、分隔线 |
| `--ink` | `#E6ECE7` | 主文本 |
| `--ink-dim` | `#97A89C` | 次要文本 |
| `--ink-faint` | `#5F7166` | 弱文本、占位符 |
| `--sig` | `#46C98D` | **信号绿**：轨道 A、统计、就绪态 |
| `--sig-dim` | `#1D4A35` | 信号绿的暗底（选中态描边底） |
| `--amber` | `#E2A23B` | **模型琥珀**：轨道 B、token 消耗、预估 |
| `--alert` | `#E0564D` | 异常、错误条 |

语义规则：绿与琥珀只用于「轨道身份」和「状态」，绝不作为装饰。
一处界面同时最多出现一种强调色（双色并列仅限压缩可视化与模式双卡）。

## 3. 字体与排印

系统栈（离线工具，零外链）：

- **数据/代码**：`ui-monospace, "Cascadia Code", Consolas, "JetBrains Mono", monospace`
  —— 所有计量数字、路径、报告 code、时间戳。
- **正文**：`-apple-system, "PingFang SC", "MiSans", "Microsoft YaHei", sans-serif`

字阶（紧凑克制）：

| 级 | 值 | 用途 |
|---|---|---|
| xs | 12px | 辅助说明、路径 |
| sm | 13px | 标签、表格 |
| base | 14px | 正文、控件 |
| md | 16px | 卡片题 |
| lg | 22px | 区块编号旁的标题、报告 H2 |
| xl | 34px | 压缩可视化大数字（唯一允许的巨字） |

标题配 `letter-spacing: .02em`；步骤编号（01–04）用等宽 + `--ink-faint`，
它们是真序列（管线阶段），编号承担导航职责。

## 4. 布局

```
┌────────────────────────────────────────┐
│ 顶栏：品牌 ▍日志夜巡   ● 后端在线  [设置] │  sticky
├────────────────────────────────────────┤
│ ① 投放日志                              │
│   ┌──────────────────────────────┐      │
│   │   拖拽区（虚线框，全宽）        │      │
│   │   ── 或 服务器本地路径 ──      │      │
│   │   模版 ▾   [轨道A卡|轨道B卡]   │      │
│   │   桶粒度 ▾  块大小 [300]      │      │
│   │   [ 预估分析 → ]              │      │
│   └──────────────────────────────┘      │
│ ② 压缩预估（出现时才渲染）                │
│   8.03 MB ⇢ 压缩 ~99% ⇢ 75,061 tokens   │  ← 签名元素
│   ┌ 指标阵列 2×4（等宽数字右对齐）┐       │
│   [ 开始分析 ]（忙态=扫描线动画）          │
│ ③ 分析报告（Markdown 深色渲染）           │
│ ④ 历史档案（点击载入 → ③）                │
└────────────────────────────────────────┘
```

- 主列 `max-width: 860px` 居中；桌面端各阶段左侧有步骤轴（竖线+节点），
  移动端（<680px）退化为纯单列。
- 空态即邀请：历史为空时显示「尚无档案——投放今晚的第一份日志」。

## 5. 交互与动效

动效预算全部花在管线节奏上，别处安静：

| 场景 | 动效 | 时长 |
|---|---|---|
| 阶段卡片出现 | fadeUp（位移 8px + 淡入） | 320ms |
| 模式双卡选中 | 边框与角标变色，无位移 | 即时 |
| 预估/分析进行中 | 按钮扫描线（`::after` 平移） | 循环 1.1s |
| 历史项 hover | 左侧 2px 信号绿边条 + 微底色 | 120ms |
| 弹窗 | 遮罩淡入 + 卡片上移 12px | 180ms |

`prefers-reduced-motion: reduce` 时以上全部禁用（仅保留透明度切换）。
键盘焦点可见：所有控件 `:focus-visible` 有 2px `--sig` 外环。

## 6. 响应式

| 断点 | 行为 |
|---|---|
| ≥680px | 桌面：步骤轴 + 指标阵列 4 列 + 模式双卡并列 |
| <680px | 单列；表单标签上置；模式双卡竖排；报告表格 `display:block` 横向滚动；顶栏品牌副题隐藏 |

## 7. 无障碍与质量底线

- 全部交互控件为原生元素（label-for、radio 保留可聚焦，视觉隐藏不裁剪焦点）。
- 文本对比：正文 `--ink` on `--bg` ≈ 13:1；最弱的 `--ink-faint` 仅用于非必要装饰字。
- 错误条为 `role="alert"`，10s 自动消退可手动关闭。

## 8. 禁忌（不做清单）

- 不用第三种强调色；不加渐变；不引入外部字体/图标 CDN（离线约束）。
- 数字永远等宽右对齐，不用比例字体混排计量。
- 不做庆祝性动画（分析完成不放彩带）；完成态用内容本身表达。
